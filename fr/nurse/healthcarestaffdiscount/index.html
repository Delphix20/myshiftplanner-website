Programme pour le personnel soignant

Réductions pour les équipes soignantes

Mon Planning Infirmier aide les infirmières à organiser les horaires de rotation, les heures de travail, le salaire estimé, les rappels et plusieurs lieux de travail dans un seul planificateur privé.

Rabais sur le lieu de travail et l’éducation

Jusqu'à 50 % de réduction est disponible pour les hôpitaux, les recruteurs et les programmes de soins infirmiers qui souhaitent partager Mon Planning Infirmier avec le personnel de santé.

Ouvrez le dépliant du programme pour un aperçu ou contactez-nous pour discuter de l'éligibilité et de la meilleure option pour votre organisation.

20 % de réduction pour les nouveaux utilisateurs
