How a 4-on/4-off shift pattern works

Four scheduled workdays are followed by four rest days. Because the cycle is eight days long, the pattern moves steadily through weekdays and weekends instead of resetting every Monday.

Published and reviewed August 26, 2026

The repeating eight-day cycle

The base sequence is simple: work four days, rest four days, repeat. What often causes confusion is the calendar movement. If the first block begins on Monday, the next begins on Tuesday, then Wednesday, because each full cycle is one day longer than a seven-day week.

Days 1-4

Work block

Record the actual start and end time for each shift.

Days 5-8

Rest block

Four scheduled rest days before the next cycle.

Next cycle

Moves by one weekday

The next work block starts one weekday later.

Days and nights may follow another rule

The work/rest pattern does not say whether a block is made of day shifts or night shifts. Some employees stay on one shift time. Others rotate after a set number of cycles. Record the time assignment explicitly and avoid using color as the only distinction.

Confirm the first workday

  1. Choose the first date in a confirmed four-shift block.
  2. Verify that four rest days follow it.
  3. Check the next work block and its day/night assignment.
  4. Review exceptions such as overtime, swaps, training, or leave separately.

What to review across a month

Look at consecutive shifts, weekend frequency, cross-midnight work, total hours, travel between workplaces, and changes between day and night blocks. Weekly totals can look uneven because a payroll week may split a four-day block.

Use the official roster as the source

A correct repeating sequence can still be wrong for your team if the anchor date or shift-time assignment is different. Verify generated dates before setting reminders or planning around them.
