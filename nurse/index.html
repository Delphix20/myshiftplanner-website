Core features

Focused, professional, and intentionally simple. The app is built to be useful in everyday nursing work, not overloaded with distractions.

Shift calendar A month-by-month calendar that makes registered shifts easy to spot at a glance.
Quick multi-day adding Set a shift once and place it across multiple dates faster when building a month.
Rotation presets Apply recurring work patterns faster and keep future months organized with less manual work.
Daily shift detail Open any day to review scheduled shifts, symbols, timing, notes, and workplace details.
Nurse shift types Track day, night, overtime, on-call, callback, PTO, sick, education, and more in one planner.
Estimated pay Review monthly gross pay estimates using base rate, differentials, overtime, and bonuses.
Work profiles Manage multiple workplaces in one calendar and assign shifts to the correct profile.
Shift reminders Get local reminders before upcoming shifts so important workdays are harder to miss.
CSV and PDF exports Export monthly records in clean formats that are easier to review, save, or share.
Private by design Use fast local storage by default with optional private iCloud sync when enabled.
